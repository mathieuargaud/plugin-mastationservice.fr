# Politique de confidentialité de l'extension MaStationService

Dernière mise à jour : 11 novembre 2026.

L'extension Chrome MaStationService affiche les stations-service les moins chères autour de vous. Cette page explique quelles données elle utilise.

## Position

Si vous l'autorisez, l'extension demande votre position au navigateur à l'ouverture de la popup ou quand vous cliquez sur « Ma position ». Cette position est envoyée uniquement à l'API de www.mastationservice.fr, pour obtenir les stations voisines. L'extension ne la stocke pas et ne la transmet à personne d'autre.

Si vous saisissez une ville, son nom est envoyé à la même API pour trouver la commune correspondante.

## Données stockées

L'extension mémorise seulement le carburant que vous avez choisi, dans l'espace de stockage de Chrome (`chrome.storage.sync`). Cette donnée peut être synchronisée par Chrome entre vos appareils si la synchronisation est activée.

## Ce que l'extension ne fait pas

- Pas de compte, pas de cookie, pas de publicité.
- Pas de mesure d'audience ni de traçage.
- Aucune donnée vendue ou cédée à des tiers.

## Côté serveur

Comme tout site web, le serveur de www.mastationservice.fr reçoit l'adresse IP des requêtes. Elle sert à limiter le nombre de requêtes par minute et n'est pas utilisée pour vous identifier.

## Contact

Pour toute question : page de contact de www.mastationservice.fr (https://www.mastationservice.fr/contact).
