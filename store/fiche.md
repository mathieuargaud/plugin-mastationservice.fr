# Fiche du Chrome Web Store

## Nom

MaStationService – prix des carburants

## Description courte (132 caractères maximum)

Les stations les moins chères autour de vous, en temps réel.

## Catégorie

Outils (ou « Voyages » selon les catégories proposées au moment de la soumission).

## Langue

Français.

## Description longue

Trouvez en un clic les stations-service les moins chères autour de vous.

MaStationService affiche les 6 stations les moins chères dans un rayon de 20 km, pour le carburant de votre choix : gazole, SP95, SP98, E10, E85 ou GPLc. Les prix viennent des données publiques des prix des carburants en France, mises à jour en continu par www.mastationservice.fr.

- Votre position est détectée par le navigateur, si vous l'autorisez.
- Vous pouvez aussi saisir le nom d'une ville.
- Pour chaque station : enseigne, ville, distance, prix et âge du prix.
- Un clic sur une station ouvre sa fiche complète sur www.mastationservice.fr.
- Le carburant choisi est mémorisé.

Hors de France, ou si la position n'est pas disponible, l'extension affiche les prix de Paris.

Aucun compte, aucune publicité, aucun traçage.
